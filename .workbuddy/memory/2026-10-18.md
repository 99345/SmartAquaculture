   解决：新增 `.gitattributes` 写入 `* -text`，再 `git rm -r --cached .` 后重新 `git add -A` 才生效
   （只加文件不重置索引无效）。已用 `git cat-file blob | cmp` 校验 PDF 与 epro2 字节完全一致。
2. **GitHub SSH 22 端口被网络阻断**（`Connection refused`）。
   解决：`~/.ssh/config` 中将 `Host github.com` 指向 `ssh.github.com:443`。
